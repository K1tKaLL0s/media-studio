# Media Studio

本地媒体创作工作台的源码快照：使用 ComfyUI 工作流调用图像、视频、语音与已准备好的歌词 PV/MV 工程，并提供本机网页网关和创作 Skills。

仓库保留项目脚本、自定义节点、网页静态文件、工作流、提示预设、模型来源清单及依赖版本记录。它不包含模型权重、Python 虚拟环境、第三方软件运行目录、缓存、登录状态或私人创作素材。克隆后需要按 [安装说明](docs/INSTALL.md) 准备依赖；本仓库不是可直接启动的整机环境备份。

| 位置 | 内容 |
| --- | --- |
| `scripts/` | 本地启动器、网关、独立语音/音乐 worker 和校验下载器 |
| `runtime/ComfyUI/custom_nodes/media_studio/` | 项目自定义节点；ComfyUI 主程序需另取 |
| `web/dist/` | 本机网关使用的网页文件 |
| `workflows/api/` | Comfy API 工作流模板 |
| `prompts/` | 提示预设和字段绑定 |
| `.agents/skills/` | 与本项目配套的创作和执行 Skills |
| `config/` | 可公开配置、模型来源、依赖版本及许可证证据 |

安装完成后的本机入口为 `http://127.0.0.1:8188`（ComfyUI）和 `http://127.0.0.1:8190`（网关）。工作流中的参考图片、音频和项目占位值需要替换成自己有权使用的材料。

8GB 显存设备每次只执行一个生成任务。模型文件体积、CPU 内存和 Windows 提交额度也会影响任务能否运行；将缓存放在项目盘不能消除系统分页需求。当前公开副本没有启动模型或重新进行生成验收，具体边界见 [验证记录](docs/VALIDATION.md)。

第三方软件和模型分别遵守其原有条款，见 [来源与许可](docs/UPSTREAM.md)。仓库没有新增覆盖整个项目的开源许可证；已有许可文件仅适用于其明确覆盖的内容。
