# 验证范围

公开整理日期：2026-10-20。

本仓库是已存在的本地媒体工作台的源码副本，包含必要的可移植性与公开配置整理。本次发布不启动 ComfyUI、语音/音乐 worker 或模型，不安装软件，不重新生成媒体，也不修改系统虚拟内存、网络或安全设置。

## 已有运行目录的证据

原工作台曾完成部分 Qwen 预设/参考声音克隆、视觉生成和 PV/MV 的实际运行。原运行目录中的成功任务和媒体不随本仓库公开；它们不能证明新克隆、其他机器或每个工作流都已通过，也不能证明未实际试听的音频质量。

2026-10-20 的新增模型整合报告记录：VoiceDesign、IndexTTS 2.5 和 ACE-Step 所选的 59 个文件约 19.31 GB 已完成固定官方来源校验；Index 与 ACE 各独立环境的依赖元数据及 `pip check` 通过。新增适配器、工作流与提示字段做过静态检查。该阶段没有执行模型导入、加载、推理、GPU 适配、音质或真实取消验收。

因此，VoiceDesign、IndexTTS 2.5 和 ACE-Step 的运行验证仍需完成。已有 Qwen 或其他模型成功不能替代它们的首次验收。

## 公开副本的验证边界

发布流程核对复制范围、文件清单、明显秘密/凭据与私人路径，保留来源许可与固定版本，排除模型、虚拟环境、缓存和私人素材。具体的本次文件数量、检查结果、Git 提交与远端内容由发布交付记录提供，不在这里预填“全部通过”。

语法/JSON/路径和工作流静态检查只能证明对应结构有效；本副本没有完成完整重装与端到端模型生成测试。恢复使用时应逐环境检查依赖，再逐工作流检查输入和模型，以真实任务终态、可解码产物及实际查看/试听验收。

模型下载补充：`config/model-downloads.json` 从现有三份清单派生 94 个固定源文件与 8 组选择。32 个 LFS 文件使用官方 SHA-256，62 个普通 Git 文件使用包含 blob header 的官方 Git blob SHA-1；没有将本地计算的 SHA-256 冒称官方发布值。下载器默认计划只核验已有文件和磁盘，不传输权重；真实下载入口需显式 `--download`。断点/校验等行为以小型本地 HTTP 夹具测试，不通过重新下载真实模型证明。Linux 链接执行和 GPU 部署没有在本次 Windows 宿主上实测；对应平台测试会明确跳过。

下载器 24 项本地小型测试通过，包括 HTTP Range 续传、服务器忽略 Range 后重启、已有文件跳过、损坏与短/长响应不发布、空间不足、路径逃逸、锁冲突和 Git blob 校验。数据目录脚本 16 项 Windows 可运行检查通过，6 项 POSIX 链接/应用测试跳过。下载计划对显式空数据目录检查后保持零文件写入。这些结果不代表官方权重实际传输或腾讯云 GPU 部署已完成。

## 系统盘异常的限制

重启后的单次磁盘和分页文件快照不能回溯证明重启前空间释放的具体组成。将项目缓存和临时目录指向项目盘有助于控制后续文件位置，但不会取消 Windows 系统分页或其他程序的系统盘写入。系统诊断报告属于本机交付，不随仓库公开。
