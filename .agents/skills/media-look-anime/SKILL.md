# 二次元美术方向

先判定具体表现：漫画黑白、平涂赛璐璐、厚涂、低饱和日常、鲜明 Pop、Q版等，已有参考优先。用户只说二次元且任务可自主推进时，选一种并说明；已经问过风格选择就等待回答。不要混用相互冲突的渲染规则。

1. 建角色约束：轮廓、头身比例、脸型/眼形、发型分区与不对称特征、服装层次、固定配饰和配色。用可以对照的描述代替“美少女/帅气”；原创人物通过形状和关系设计，不把某个作者姓名当唯一风格说明。
2. 选线与形：外轮廓和内部细节的轻重、曲直节奏、阴影边缘软硬、是否用网点/纹理。角色从远看应有可识别剪影；配饰不要破坏动作与轮廓。混合媒介时指定角色、背景、文字分别采用何种规则。
3. 确定主色、次色和小面积强调色，检查明度区分；不要让所有颜色同等抢眼。阴影服务体块与注意力，避免一面赛璐璐硬阴影一面无意变成塑料3D高光。具体风格练习见 [look-cards.md](references/look-cards.md)。
4. 为表演写姿态线、视线、手势、表情强度和动作起止。漫画靠格间变化传信息；动画需要检查脸/发/衣服随时间的变形，不能只规定“灵动”。Live2D拆分、绑定和物理是另一个执行任务，本 Skill 不把立绘生成当成可用模型工程。
5. 交付角色约束卡、场景/镜头视觉卡、模型无关描述与 QA；交 media-image-prompts 用本机 Anima 等适用模型的真实标签/参数，或 media-video-prompts 写运动。相同种子不保证跨模型身份一致。

生成前固定主参考、画幅与允许变化；多视图先比脸型、发分、衣领和配饰位置，再做整批。手指/肢体、眼睛数量、遮挡、饰物穿插和文字可读是基础检查；不因风格化就放过非有意的结构错误。

视频检查首中尾与转头/眨眼中间帧，记录是否完成完整动作。例如“完整眨眼”应有睁→闭→再睁；只在尾帧闭眼不能判通过。长短发漂移、衣领变色、嘴部多出色块优先局部返工。未看实际图或运动的方案只标计划，不称角色一致。
