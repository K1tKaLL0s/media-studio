# 网页视觉评审卡

内容检查：真实标题和说明是否有层级；主要操作是否唯一清楚；相同类型的控件是否共享尺寸/样式；图片、图标与文字是否各有作用；窄屏重排是否保留阅读顺序。避免通过缩小所有文字硬塞内容。

可读性检查：按前景和背景实际颜色计算文字对比。WCAG2.2 1.4.3 AA 对正常文本为至少4.5:1，大文本至少3:1，含适用例外；不要从一张抗锯齿截图抽样就称整体合规。品牌色和低饱和本身不是豁免。来源：[W3C Understanding Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)，2026-10-20读取正文。

动效检查：每个运动说明服务的交互、持续与退出方式；支持减少动态偏好。非必要交互动画可关闭属于 WCAG2.2 2.3.3 AAA 的要求，不能误写为全部网站 AA 的同一条；自动播放另受其他标准约束。来源：[W3C Understanding Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)，2026-10-20读取正文。

例：媒体工作台的生成按钮保留唯一主强调色，工作流类型用中性分组；排队/运行状态不伪装成可点击主操作；参数解释紧邻相关字段，错误在受影响区域显示且保留已填文本。窄屏将参数和预览按任务顺序排，不裁掉提交与取消区域。此例是设计方案，不是已对本机网页完成审计。
