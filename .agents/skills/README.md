# Bundled skills

The 12 child directories are project skills. Configure `MEDIA_STUDIO_ROOT` to the repository root and follow the repository installation instructions before using local generation. `${MEDIA_STUDIO_ROOT}` in skill prose is a configured-path placeholder, not an automatically expanded Markdown value.

The eleven creative skills other than `media-studio` retain the existing [creative package MIT license](../../creative-skills/LICENSE) and [source notices](../../creative-skills/THIRD-PARTY-NOTICES.md). This does not extend that license to the separate `media-studio` skill or the rest of the repository. The author MV skill under `upstream/` retains its own license and notices. Optional installed host skills and private host instructions are not bundled.

See the [creative package guide](../../creative-skills/README.md) for the skill list, manual installation and license scope.
