# 声音创作与导演

把使用场景转成可听、可比较、可返工的说话表现。
可以独立交付音色设定、配音稿和导演意见；音频生成只调用已经可用的执行层。
本机执行由 `media-studio` 统一负责，本 Skill 不管理模型、环境或 MCP 注册。

## 先判断交付

- 音色/角色设定：交付声音 brief 与候选比较用台词，不假装已生成新声纹。
- 预置说话人配音：在现有音色上指导语速、情绪、停连与咬字。
- 授权声音克隆：从有明确本人授权的参考音色合成新台词。
- 已有语音编辑：按原音轨、源时码和目标用途剪辑，不必重新合成。
- 歌词朗读仍是说话；请求演唱、翻唱、旋律或歌曲时按音乐/歌声能力另行判断。

需要设计声音时读 [voice-direction.md](references/voice-direction.md)。
需要合成验收、长稿或编辑时读 [audio-qa-edit.md](references/audio-qa-edit.md)。
不要为一句简单配音加载无关音乐或视觉工作流。

## 输入与创作判断

先从用户已有材料提取：用途、受众、实际台词、语言、目标时长、音色/表演参考和不可改内容。
用户没有指定且不影响范围的常规选项，可以说明所选起点后继续。
只询问会改变声音身份、关键表演、材料授权或交付范围的问题，不把整张参数表交给用户填写。
已问的问题保留“待答问题—暂停范围—恢复条件”；真实答复前不推进依赖的选声、生成或交付。
原稿、原音频、准确转写与授权范围分别保留，不用处理后的文件覆盖原件。

把抽象感觉转为声音属性，并分成恒定音色与本次表演。
恒定属性包括语言/口音、音区、共鸣、明暗、气声/粗糙度与角色距离感。
表演属性包括速度、重音、停连、情绪强度、句尾和对白关系。
少量具体指令优于相互冲突的形容词；模型未提供独立控制的维度只能作为方向。
参考用于提取可听特征，不自动要求复制一个具名人物的身份。

## 编写可比较的表演

台词正文只保留要说的话；导演说明、读音提示和分段编号单独存放。
保留用户锁定的用词、数字、称呼、顺序和语义，不靠改词掩盖读音失败。
多音字、人名、数字与缩写用本任务实际台词做短测，不用无关口号比较声音。
比较候选时使用同一文本和相近输出条件，说明每版差异；不把随机波动当风格改善。
先验证一两句关键表演，再处理长稿；用户已作选择时沿用，不反复索取同一确认。
长稿按完整句或语义段落切分，保留段号和前后文，不在词音中间截断。
同一角色固定说话人/参考音频、模型与导演基线，必要的情绪变化单独标记。
需要精确时长时先用实测语速估算，再调停连、分句或经授权的稿件；避免粗暴倍速。

## 现有本地能力的实际边界

本机项目位于 `${MEDIA_STUDIO_ROOT}`。
实际合成前读取该项目 `.agents/skills/media-studio/SKILL.md` 及其 `references/voice.md`。
由它完成当前服务、输入存在、模型、节点、队列、任务副本与输出检查。
不要把技能文本、模型存在或 validator 通过当成合成/自然度已验收。

| 需要 | 当前工作流 | 必须守住的区别 |
| --- | --- | --- |
| 预置音色与表演 | `workflows/api/speech.json`，1.7B-CustomVoice | text 是台词；speaker 是实际枚举；instruct 是表演方向 |
| 参考音色说新台词 | `workflows/api/speech_clone.json`，0.6B-Base | reference_text 是参考原话；text 是新话；instruct 必须为空 |
| 从描述创造新声纹 | 当前无 VoiceDesign 适配器 | 可以交付设计 brief，不得假装 preset 已创建新声音 |
| 说话转歌声/翻唱 | 当前两个 Qwen 工作流不提供 | 不把歌词朗读交付成演唱 |

clone 参考优先干净单人、无伴奏、无强混响、稳定音量，并具备准确对应转写。
使用声纹必须有声纹主体本人的明确授权；保留已有授权的对象、用途与允许范围，不重复问已答事项。
公开可播放、用户上传或“像某人”的描述本身不等于本人授权。
外传参考或使用收费云服务前确认相应范围；不为改善音质自动上传、开通账号或安装新模型。
不同服务可能有额外要求，例如 ElevenLabs 专业克隆只能由本人账户验证自己的声音。
不把该服务的限制泛化为所有本地引擎，也不绕过服务要求。

只有当前任务使用可用生成器时才加载执行 Skill；文字声音设定不需要启动后端。
8GB GPU 按既有执行层串行规则处理，不另起并发 TTS 或私建环境。
失败、OOM、取消后先查本次任务状态，不能重复提交来碰碰运气。

## 试听与修改

先检查可解码、时长、采样率/声道、非静音、过载和文件是否属于本任务。
随后实际听内容：漏读/多读、重复、句尾截断、停顿、噪声、音色与情绪。
克隆相似度与表演自然度需要听，ASR 和波形不能代替。
没有音频感知或只读到转写时，明确验证范围并标记待试听，不称“自然”“像本人”。
音乐、房间声或多人混在参考里时，不把它们误认为目标音色特征。
按“哪句—何处—听到什么—改哪个因素”给返工意见，优先只重做失败片段。
处理后的语音回到整段上下文再听，检查拼接边缘和角色一致性。
降噪、均衡、响度或混响只针对实际问题，避免以过度处理掩盖失真。

## 交付

文字模式交付声音 brief、可直接使用的稿件/导演说明及尚未实现的控制项。
音频模式交付可打开的实际文件、台词/段落对应关系、必要参数与 QA 结论。
区分“已生成”“技术检查通过”“已实际试听”三种状态，未做的检查写明。
未获授权的克隆、缺参考转写、执行层不可用或需要收费时，暂停相应动作；若已为此发问，也暂停依赖答案的选声、设计和交付，不能把暂停范围缩成仅不提交。
不把未生成的设计稿称成成品音频，不把说话音频称成歌曲。
