# 写实审美操作卡与依据

光线先观察脸和物体的明暗交界、投影、眼神光及反射，再反推可能的光源。生成前写光源关系，生成后检查是否真成立；提示中“window light”不证明图中只有一个光源。直射、反射和侧光可服务不同情绪，不把柔光当唯一正确方案。

例：写实产品图的目标是陶杯使用痕迹。构图为桌面高度三分之二侧面，杯口轮廓不与窗框重叠；主光从画面左侧大窗进入，杯右侧保留较暗釉面，木桌反光温暖；主体边界清楚，避免白釉溢出高光。检查杯柄连接、椭圆透视、杯底接触影和反射位置。需要大字标题时留字区并后期排字。

依据：Nikon / Chris Ogonek 的 [The Basics of Flash Photography](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/the-basics-of-flash-photography)，2026-10-20读取正文。吸收的是光线方向、反射面颜色与形体塑造的关系，没有复制照片或器材曝光配方；摄影经验不等于某生成模型的能力保证。本操作卡的生成质检和交接方式为本包原创整合。
