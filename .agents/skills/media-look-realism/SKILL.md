# 写实视觉方向

输入：用户参考或目标受众/用途、主体和行为、环境、画幅、需要保留的真实属性；检查已有图片再评审，不凭未见画面判断。给定风格或参考优先，不默认磨皮、浅景深、金蓝调色或所有场景三点布光。

1. 用一句叙事意图定义观众看见什么，例如“晨间厨房的普通劳动，重点是手与旧陶杯的接触”。选一个主视觉中心，明确前中后景和视线/运动空间。写取景距离、机位与透视倾向；焦距数字只作为意图提示，不保证生成模型模拟真实光学。
2. 写光线设计：可解释的主光来源、相对方向、大小/软硬、补光或阴影保留、背景分离、色温关系和曝光重点。室内反射表面的颜色也会影响人物；不要仅增加亮度解决平面感。来源与学习边界见 [craft.md](references/craft.md)。
3. 给主体两三条材质证据：皮肤保留细微色差但不过度颗粒，陶釉与金属的高光宽度不同，旧布折痕服从受力。缺陷要有位置和尺度理由；噪点不是质感，添加污渍也不是写实充分条件。
4. 固定现实关系：接触点、阴影方向、反射主体、透视/尺度、重力、遮挡、手持物和人物身份。视频另写运动起止与光线连续性，不把单帧好看等同于整段可信。
5. 输出短视觉简报和一个可执行镜头描述，再交 media-image-prompts 或 media-video-prompts 翻译为目标模型语法。没有指定模型的审美设计不要擅自填 CFG/负提示参数。

产出应含“保留/强化/避免”各1–3项、主光和构图说明、参考应用位置、画面描述及检查点。审美冲突时说明取舍，例如纪实细节优先则让背景可读，不能同时要求所有背景彻底虚化。

评审按影响排序：叙事焦点 → 形体/空间 → 光与材质 → 局部纹理。先看缩略图是否读得清，再看正常尺寸和必要局部；视频看首中尾及接触/转身关键帧。分“可见问题、推测原因、最小修订”三项；没有播放/看图证据就写待验，不称真实或一致。

典型修订：“更写实”改为“保留人物皮肤色差；把额头均匀白亮改为左侧窗光渐变；桌脚接触影贴合地板；撤掉杯沿额外指节”。不同时重置人物、背景、色调和镜头，否则无法判断改动原因。
