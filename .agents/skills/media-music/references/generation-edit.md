# 已有引擎的生成交接与音轨剪辑

用户要求实际生成或编辑音频时读取；不把候选引擎文档当本机已安装的证明。

## 核对真实接口

先查当前已发现工具/明确提供的本地端点、模型/版本及该版本官方接口；不要从同名技能或教程猜可用性。
确认任务是整曲 text-to-music、局部重做、参考风格、结构 cover、歌声转换还是分轨，字段和材料分别核对。
选择当前确实支持的模式，把源录音、参考音色、歌词和源/目标时间区间分开。
本机 media-studio 目前没有音乐生成节点；Qwen 是说话，PV/MV 节点是项目渲染。
没有已验证入口时只交付生成简报，不自行 clone、安装、训练或新增付费账户。
收费云、上传材料或把本地任务转远端，需要用户明确同意相应动作；保留已有有效授权，不重复确认。

引擎交接记录至少包含：实际引擎与版本/端点；模式；歌词/结构；全局风格/配器；专用元数据；参考/源文件；局部区间；seed；输出目录与检查方式。
生成前确定真正的输入文件存在，模板占位名和 workflow validator 通过不能代替材料检查。
每次保留本次简报和参数，不能为返工修改唯一原件。

## 已核读的接口示例，不代表本机已接入

ACE-Step-1.5 固定研究版本的官方 Python 接口是：
`GenerationParams`、`GenerationConfig`，再由 `generate_music(dit_handler, llm_handler, params, config, save_dir=...)` 产生结果。
`result.success` 后仍须检查 `result.audios` 中真实 path；失败读取 `result.error`。
这个示例说明如何核对接口合同，不要求创建新程序或初始化 GPU handler。
参数需以实际可用安装版本为准；[官方 INFERENCE.md](https://github.com/ace-step/ACE-Step-1.5/blob/ca1e85fe9430179831e6bc6be790c332190a3866/docs/en/INFERENCE.md) 已核读。

| 创作内容 | 该研究版本的字段/区别 |
| --- | --- |
| 整体风格、配器、演奏/演唱质感 | caption |
| 要唱的字、段落时间结构 | lyrics；标签能力需按模型核对 |
| 速度、调性、拍号、时长 | bpm、keyscale、timesignature、duration |
| 全局声学风格参考 | reference_audio；不等于精确保留旋律 |
| 非 text2music 的结构源材料 | src_audio；不同任务/模型支持不同 |
| 局部修改 | task_type 与 repainting_start/end，区间合同需核对 |

上游任务/字段不自动说明每个模型都支持，元数据也可能只是引导；实际 BPM/调/时长仍需测听。
若可用的是其他引擎，读取它的实际工具 schema 与当前官方文档；不要复用此表的字段名。
同理，ElevenLabs 的 prompt 与 composition_plan 路径不能假设可同时输入，账号/费用与功能许可另核对。
工具返回接受后跟踪原任务；超时先查状态，避免双重提交。完成需真实音频与内容验收。

## 音轨剪辑与配乐

先记录原始文件和源区间、目标时间线/帧率、采样率/声道、对白/环境声与输出规格。
按乐句和叙事目的选入出点；延长可用结构重组/循环或经授权局部再生，不能无说明地拉伸整曲。
变速会影响律动与音色，是否保调、如何对齐都需按实际工具能力和听感确认。
剪辑决定的交叉淡化不是消除所有问题的通用解法，重叠要核对和声、节拍、瞬态与人声是否互撞。
旁白下先减少抢位的编配/频段与密度，必要时再做音量自动化；不让对白长期埋在配乐里。
分轨后检查分离伪影、相位/低频及重混音质量，不能因有 stems 文件就称可商用母带完成。
保留干净尾音和自然余响；循环首尾、转场和成片末尾在完整上下文反复听所需范围。

FFmpeg [atrim](https://ffmpeg.org/ffmpeg-filters.html#atrim) 不重置时间戳，拼接按需重新归零；不要直接沿用错误时间基。
[acrossfade](https://ffmpeg.org/ffmpeg-filters.html#acrossfade) 会因重叠影响长度；[loudnorm](https://ffmpeg.org/ffmpeg-filters.html#loudnorm) 支持双遍文件分析，响度/真峰值目标依据交付规范。
使用已安装工具时先核对真实命令帮助与文件路径，不在本 Skill 固化未知版本参数或安装依赖。

## QA 与交付记录

技术检查：实际时长、可解码、非静音、采样率/声道、削波与必要响度；原始与处理后不要混淆。
听评：动机/结构、拍点、歌词漏字/咬字、音准、情绪弧、对白遮挡、接缝、混响尾音与压缩失真。
需要时检查单声道折叠和小音量播放，确认核心信息仍可辨。
最终把目标、实际测量和主观听评分开写；未听的地方明确标记，不能只看文件或转写就称达标。
交付原音轨到编辑版的时间映射、创作/生成参数与已接受版本，保留返工定位。
