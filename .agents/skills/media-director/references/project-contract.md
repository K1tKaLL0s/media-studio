# 项目与交付约定

在用户指定目录或 ${MEDIA_STUDIO_ROOT}\projects 下建立独立项目；已有项目沿用，不覆盖模板 demo。纯文本草案可先交付对话或文档，不为每句创意建空工程。

最小信息记录：任务目标、现有决定、材料来源与授权、待答问题及暂停范围、当前阶段、素材 ID、输出路径、实际质量证据。仅在真正多阶段项目时维护一份简短项目记录；不引入数据库或新调度器。

关联字段：
- SC01 场次：人物目标、阻碍、结果；事实型内容则是要点与可核对来源。
- SH01 镜头：目的、构图、动作、时序/无时间码、前后连续性、关联台词和音乐 cue。
- AS01 素材：角色/场景参考、版本、文件、来源、用于哪些镜头。
- C01 音乐/声音 cue：入点、出点、叙事功能、来源、音量/留白意图。

提示词交接保留：目标模型和版本、文字 prompt、参考材料及实际接口槽位、独立参数、预期可见行为、不可改变内容、输出规格。不要把无效 flags 隐藏在 prompt 中。执行记录追加实际工作流副本、prompt_id、终态、输出路径，不编造尚未返回的字段。

返工按最小影响集：拼字错修字卡；动作不达标修该镜；身份漂移先修主参考/镜头起始帧；对话听不清先修配乐让位和该句；只有主题/情节根本不成立才回到故事。列明未看、未听和未测的范围。

动效项目会编写长期保存的 timeline.js/scene 等程序时，正式规划/修改前读用户宿主与当前项目的代码执行规则并交付对应机械执行书；UI 实施模型和分工沿用已覆盖本项目的用户决定，未覆盖时才问。此 Skills 包不是绕过项目规则的预授权。
