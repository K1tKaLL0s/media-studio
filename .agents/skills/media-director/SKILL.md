# 媒体创作总控

先读用户材料、当前项目记录和已有决定，定位最先缺失的创作产物。只加载本次所需子技能，不把整个包一次注入。已有成稿直接进入制作或返工；不要强迫用户重新经历立项。

## 建立可检查的创作约定

把目标写成一句可观察的结果，例如“用已授权音轨制作横屏歌词 PV，副歌出现信使抉择，歌词不挡脸”，不要以“高级、震撼、电影感”代替内容。记录受众、用途、材料、必留文字/事实、交付媒介、时长或无时间码、画幅、审美、模型/执行方式、预算约束和验收重点。能由明确范围推定的常规选择直接说明并做；只问会实质改变结果的缺项。

一旦发问，保留“待答问题—暂停范围—恢复条件”。真实回答、撤回或明确授权自主决定前，不继续依赖问题的研究、设计、生成或交付，也不通过子代理继续。每次工具调用前核对该记录。没有独立必要工作时交还回复机会。部分回答仅恢复对应分支。

## 推进与交付

按“故事/信息 → 镜头 → 提示与音频/音乐 → 生成或制作 → 画面与声音检查”推进必要部分。用稳定 ID 关联场次、镜头、素材、台词与 cue；修改故事时标出受影响镜头，修改一张图不重做全部音乐。参见 [项目与交付约定](references/project-contract.md)。

先用一个有代表性的片段判断方向；用户已要求全片且方向明确时继续全片，不另加人为审批。若主动请求选方向、角色或预览确认，就等真实答复再推进依赖内容。

实际执行前读 [本机能力与限制](references/local-capabilities.md) 和 media-studio。保持 N 盘项目材料；本机 GPU 串行，不为调研加载模型。云端付费或外传材料前确认具体服务、材料和本次用途；没有确认时停在可审阅简报。不要把程序/上传发布/新后端安装混作创作授权。

交付指出“已有产物、观察证据、未达到的要求、最小返工范围”。提示词、分镜和方案属于设计产物；终态成功只证明技术任务完成；角色一致、动作正确、说话自然、节奏合适必须由看图/播放/听音等证据支持。技术通过与内容质量分开记录。
