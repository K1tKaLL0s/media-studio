# 来源与观察范围

研究核对日期为 2026-10-20。本目录保留创作包的来源元数据和研究摘要。公开 URL、作者、固定提交、可用内容哈希、观察方法和限制仍在；原视频、抽样帧、网页缓存、宿主状态及其他本地研究证据文件不随仓库分发。JSON 中原机器绝对路径已移除，部分未分发证据仅保留文件名用于识别，不能作为本仓库可打开的文件引用。

story-directing / story-sources：视频样本、StudioBinder 教学、ScreenSkills 职业技法与导览方法。
model-prompting / model-sources：模型文档、工作流观察、版本冲突与本地测试的历史边界。
audio-music-community / audio-community-sources：声音/音乐资料、社区 Skill/插件的固定提交、许可及已读文件哈希。
root-viewing-and-aesthetics：补充播放器观察与审美来源。

metadata 只指标题、作者和时长等信息；preview_frames 只指实际看过的抽样预览帧；web_text 只指读过的页面/文档；playback_observation 只覆盖记录的时点或区间；listen 仅在实际听过音轨时成立。空字幕响应不说明原片无语音，离散画面不证明完整连续动作或听感质量。

原研究没有对所有视频宣称完整连续观看或听音。访问失败、只经搜索定位、PDF 超时等限制应与来源一同保留。作者关于成本、显存、速度、排名和效果的陈述只是作者主张；本地可用性依赖当前实际安装和运行结果。该公开源码副本没有重新运行教程或模型，且不包括历史私有生成素材。
